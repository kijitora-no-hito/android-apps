Phonetic Hound プライバシーポリシー

制定日: 2026年9月25日（Phonetic Hound 0.1.0-dev）／ 最終更新日: 2026年10月18日（協力プレイを追加）

収集する情報

Phonetic Hound（以下「本アプリ」）は、利用者の個人情報を収集しません。 アカウント登録は不要で、氏名・メールアドレス・位置情報・端末の識別子などを取得することはありません。 本アプリが求める権限はインターネット接続だけです（下の「更新の確認」のため）。

端末内に保存されるデータ

ゲームの進行状況（制圧した基地局、所持品、地図の踏破状況、置いたピンなど）とランキング（名前・記録）を、端末内のアプリ専用領域に保存します。 外部には送信しません。本アプリをアンインストールすると削除されます。 なお、端末の設定で Android 標準のバックアップを有効にしている場合、このデータは Android の仕組みにより 利用者自身の Google アカウントのバックアップに含まれることがあります（開発者はその内容を見られません）。

結果の共有

リザルト画面の「結果を共有」を押すと、ステージの結果（ステージ名・クリアタイム・撃破数など）の画像と文章を作り、 Android の共有機能で、利用者が選んだアプリ（SNS など）に渡します。本アプリ自身が送信することはなく、 共有するかどうか・どこに送るかは利用者が決めます。共有用の画像は端末内の一時領域に作られます。 ランキング（名前・記録）は端末内だけに保存し、外部には送信しません。

BGM に使う音楽ファイル

設定で BGM を「MP3（自分で選んだ曲）」にすると、利用者が Android のファイル選択画面で選んだ音楽ファイルを BGM として再生します。 本アプリが読めるのは選んだファイルだけで（そのファイルを読む許可を Android から受け取ります。ストレージの権限は求めません）、 端末内で再生するだけです。ファイルを送信・複製・変更することはありません。設定に残るのは、選んだ曲の場所と表示名だけです。

更新の確認

起動時に、GitHub（raw.githubusercontent.com）にある本アプリの公開リリース一覧（releases.json）を 1 回取得し、新しい版があればタイトル画面でお知らせします（前回の確認から 6 時間以内は取得しません）。 送信するのは通常の Web の読み込みと同じ HTTPS のリクエストだけで、ゲームのデータ・プレイ内容・端末の識別子などは送りません。取得の際、GitHub（GitHub, Inc.）に IP アドレスなど通常の通信の情報が届きます。 設定の「更新の確認」を OFF にすると、本アプリは一切通信しません。［ダウンロード］［説明を見る］はブラウザで GitHub のページを開くだけで、本アプリがファイルをダウンロード・インストールすることはありません。

Windows 版

Windows 版は、セーブ・設定・ランキング・画面の設定と、起動ごとの動作の記録（log.txt）を %APPDATA%\PhoneticHound に保存します。外部には送信しません。アンインストールのときに消すかどうかを選べます（既定は残します）。 結果の共有は、画像を「ピクチャ\Phonetic Hound」に保存し、投稿用の文章をクリップボードに入れるだけです。BGM の自分の曲は、Windows のファイル選択で選んだファイルを PC の中で再生するだけです。 更新の確認は Android 版と同じです（設定で OFF にすると一切通信しません）。

協力プレイ

協力プレイ（サバイバルを 2〜6 人で遊ぶ機能）を開いたときだけ、作者の中継サーバ（taisen-game.com）に接続します。送るのは、部屋番号・ゲームの操作と画面の中身・協力プレイで使う名前・Lv と装備・端末ごとのランダムな識別子（同じ部屋で抜けて入り直したときに見分けるため。ホストの端末が部屋のある間だけ使い、保存しません）です。 中継サーバは同じ部屋の人へ転送するだけで、中身・部屋番号・名前を記録・保存しません（記録するのは接続数・部屋数などの数だけです）。通信には接続元の IP アドレスが必要です。番号の入力を何度も間違える接続を止めるため、IP アドレスをその場で読めない形にしたものだけをメモリに最大 10 分持ちます。また、通信の暗号化を受け持つウェブサーバのアクセスログには、一般的なウェブサイトと同じく接続元の IP アドレスと日時が残ります。 部屋は番号を知っている人だけが入れ、知らない人とはつながりません。自由な文字のチャットはありません（決まった言葉のスタンプだけです）。協力プレイを使わなければ、この中継サーバには接続しません。

第三者への提供

本アプリは広告や解析のための外部サービスを組み込んでおらず、第三者にデータを提供しません。
