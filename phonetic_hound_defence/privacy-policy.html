Phonetic Hound Defence プライバシーポリシー

制定日: 2026年10月5日（Phonetic Hound Defence 0.3.0-dev）／ 最終更新日: 2026年10月5日（0.6.0-dev・更新の確認を追加）

収集する情報

Phonetic Hound Defence（以下「本アプリ」）は、利用者の個人情報を収集しません。 アカウント登録は不要で、氏名・メールアドレス・位置情報・端末の識別子などを取得することはありません。 本アプリが求める権限はインターネット接続だけです（下の「更新の確認」のため）。

端末内に保存されるデータ

ステージのクリア状況と評価（★）、設定（音量・中継器の置き方・更新の確認など）を、端末内のアプリ専用領域に保存します。 外部には送信しません。本アプリをアンインストールすると削除されます。 なお、端末の設定で Android 標準のバックアップを有効にしている場合、このデータは Android の仕組みにより 利用者自身の Google アカウントのバックアップに含まれることがあります（開発者はその内容を見られません）。

更新の確認

起動時に、GitHub（raw.githubusercontent.com）にある本アプリの公開リリース一覧（releases.json）を 1 回取得し、新しい版があればタイトル画面でお知らせします（前回の確認から 6 時間以内は取得しません）。 送信するのは通常の Web の読み込みと同じ HTTPS のリクエストだけで、ゲームのデータ・プレイ内容・端末の識別子などは送りません。取得の際、GitHub（GitHub, Inc.）に IP アドレスなど通常の通信の情報が届きます。 設定の「更新の確認」を OFF にすると、本アプリは一切通信しません。［ダウンロード］［説明を見る］はブラウザで GitHub のページを開くだけで、本アプリがファイルをダウンロード・インストールすることはありません。

第三者への提供

本アプリは広告や解析のための外部サービスを組み込んでおらず、第三者にデータを提供しません。

お問い合わせ

GitHub の Issues までお願いします。

改定

本ポリシーを改定するときは、このページで改定日とともにお知らせします。
