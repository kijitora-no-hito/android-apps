学会メモ プライバシーポリシー

「学会メモ」（以下、本アプリ）は、学会の聴講中にスライドの写真とメモを講演ごとに残すためのアプリです。 本アプリは利用者の個人情報を収集しません。開発者や外部のサービスへ送ることもありません。

本アプリはインターネットに接続しません（インターネットの権限を持っていません）。 撮影した写真・取り込んだ予稿・入力したメモは、端末の中のアプリ専用の領域だけに保存されます。 写真は端末のギャラリー（写真アプリ）にも保存しません。

1. 取り扱う情報

情報保存場所外部送信
セッション（学会名・セッション名・日付・会場）、講演（タイトル・講演者）、本文のメモ、写真に付けたメモ 端末内のアプリ専用領域（データベース） なし
本アプリのカメラで撮影した写真（スライド・タイトルの代わりの写真・予稿） 端末内のアプリ専用領域 なし
利用者が選んで取り込んだ画像・PDF（予稿など） 端末内のアプリ専用領域に写しを保存します。画像は取り込むときに作り直すため、元の画像に含まれる位置情報などの付加情報は残りません なし

本アプリは、広告・アクセス解析・クラッシュレポートのいずれのサービスも組み込んでいません。 利用状況の記録や送信も行いません。アカウント登録もありません。

2. 撮影について

本アプリのカメラは撮影時にシャッター音を鳴らしません（撮った合図は画面の表示で行います）。 撮影が許可されている講演・場所でだけお使いください。 学会・講演者が撮影や撮影した写真の公開・共有を禁じている場合は、その決まりに従ってください。 人物を無断で撮影したり、他人に迷惑をかける目的で使ったりしないでください。

3. 書き出し・共有・バックアップ

利用者が「書き出し」「共有」「バックアップ」を操作したときだけ、 講演のメモ（Markdown）・写真・予稿、またはすべてのデータを ZIP ファイルにして、 利用者が選んだ保存先・共有先のアプリへ渡します。本アプリが自動でどこかへ保存・送信することはありません。 保存先・共有先（クラウドストレージやメールなど）での取り扱いは、そのサービスに従います。

Android の自動バックアップ（Google アカウントへのバックアップ・機種変更時のデータ転送）には、 メモのデータベースと設定だけが含まれます（写真・予稿は容量が大きいため含めません）。 写真まで移すときは、設定画面の「バックアップ」で作った ZIP を新しい端末で復元してください。 自動バックアップの扱いは Google の規約に従います。端末の設定で自動バックアップを止めることもできます。

4. 権限について

本アプリが使う権限はカメラ（CAMERA）だけです。スライドなどの撮影のためだけに使い、撮影画面を開いている間だけカメラを使います。 位置情報・マイク・連絡先・インターネットなどの権限は使いません。 画像・PDF の取り込みには Android 標準の選択画面を使い、利用者が選んだファイルだけを読み込みます。

5. データの削除

セッション・講演・写真・予稿はアプリ内から個別に削除できます。 アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。 残しておきたい場合は、アンインストールの前に「設定 → バックアップ」で控えを取ってください。

6. 第三者提供

本アプリの開発者は、利用者のデータを取得しません。したがって第三者へ提供することもありません。

7. 配布元について

本アプリは GitHub での APK ファイルの直接配布で提供しています。 ダウンロードの際、GitHub（GitHub, Inc.）に IP アドレスなど通常の通信の情報が届きますが、これはブラウザでの Web の閲覧と同じもので、本アプリが送るものではありません。

8. ポリシーの変更

内容を変更する場合は、本ページを更新し、改定日とともにお知らせします。

9. お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせ先: GitHub の Issues
