# android-apps（Release のタグ用）

このコミットは GitHub Releases のタグを付けるためだけのものです。
Release の「Source code (zip / tar.gz)」は GitHub が自動で付けるもので、中身はこのファイルだけです。アプリのソースコードは配布していません。

配布物は各 Release に添付した APK だけです。

- 説明・インストール方法: https://kijitora-no-hito.github.io/android-apps/
- 問い合わせ: https://github.com/kijitora-no-hito/android-apps/issues
