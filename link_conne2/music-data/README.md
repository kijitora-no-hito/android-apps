# りんくこねこね 楽曲データ / Link Conne2 tune data (ODbL)

このフォルダは、アプリに同梱している譜面データ（派生データベース）を
ODbL の Share-Alike 条項に従って公開するためのものです。

This folder publishes the tune transcription data bundled with the app
(a Derivative Database) as required by the ODbL share-alike terms.

## 中身 / Contents

| ファイル | 内容 |
| --- | --- |
| `*.abc` | 譜面データ 8 曲（ABC 記譜） |
| `credits.json` | 曲ごとの出典・採譜者・元 URL |
| `LICENSE.txt` | ライセンス表記・著作権表示・加えた変更 |

## 公開先 / Published at

<https://drive.google.com/drive/folders/1SfqH3V8z9xQmKWMSXFSYBVEwY7y9Jj4S?usp=sharing>

この URL は `app/src/main/assets/music/credits.json` の `dataUrl` に設定済みで、
アプリの「設定 → クレジット → 楽曲データの公開先」に表示されます。

## 譜面を追加・変更したら

このフォルダの内容を更新し、上記の公開先にも上げ直してください。
ODbL の Share-Alike は、派生データベースを更新した場合にも適用されます。
