話題コンパス プライバシーポリシー

「話題コンパス」（以下、本アプリ。Android 版と Windows の PC 版があります）は、懇親会や飲み会などに向けて話題の案を準備するためのアプリです。 本アプリは利用者の個人情報を収集しません。開発者や外部のサービスへ送ることもありません。

本アプリはインターネットに接続しません。 入力した内容は端末（PC 版では PC）の中だけに保存されます。 通信するのは、利用者が「Wi-Fi でやりとり」を始めたときに、同じ Wi-Fi（LAN）の中にある利用者自身の機器（PC・スマホ）と直接データを受け渡すときだけです。 この通信は暗号化し、インターネット上のサーバーや開発者を経由しません。 話題のヒントはアプリに同梱した文章から選んで表示しているだけで、生成 AI や外部のサービスには問い合わせません。

1. 取り扱う情報

情報保存場所外部送信
人物メモ（呼び名・関係・組織・業界・出身地・住んだことのある地域・趣味・タイプ、日付つきのメモ）と自分のプロフィール 端末内のアプリ専用領域（データベース。PC 版は %APPDATA%\TalkCompass） なし（利用者が「Wi-Fi でやりとり」で自分の機器へ送るときを除く）
予定（日時・場面・お店・料理・参加者・メモ）、話題案、振り返りの評価、一言メモ 同上 同上
ネタ帳、自分で追加した趣味 同上 同上
端末の名前（Android の「デバイス名」または機種名、PC 名） 保存しません 「Wi-Fi でやりとり」のときだけ、相手の機器の画面に表示するために送ります

本アプリは、広告・アクセス解析・クラッシュレポートのいずれのサービスも組み込んでいません。 利用状況の記録や送信も行いません。アカウント登録もありません。

2. 人物メモについて

人物メモには、利用者が入力した他の人の情報（呼び名・勤め先の業界・出身・趣味・会話のメモなど）が含まれます。 これらは端末の中だけに保存され、本アプリが外部へ送ることはありません（利用者が「Wi-Fi でやりとり」で自分の機器へ送るときを除きます）。 書き出したファイルを他の人と共有したり、クラウドストレージに保存したりするときは、その扱いにご注意ください。 「Wi-Fi でやりとり」は自分の機器どうしで使い、他の人の機器へは送らないでください。

3. 書き出しと読み込み（バックアップ・PC とのやりとり）

「データと設定」の［書き出す］を押したときだけ、すべてのデータを 1 つの JSON ファイルにして、 利用者が標準のファイル選択画面（Android / Windows）で選んだ場所に保存します。書き出したファイルには端末の名前も入ります。 ［読み込む］は利用者が選んだファイルだけを読み込みます（今のデータに足す「追加・更新」か、置き換えるかを選びます）。本アプリが自動でどこかへ保存・送信することはありません。 保存先（端末内、SD カード、クラウドストレージのアプリなど）での取り扱いは、その保存先のサービスに従います。

本アプリは Android の自動バックアップ（Google アカウントへのクラウドバックアップ・機種変更時のデータ転送）の対象から外しています。 機種変更のときは、書き出したファイルを新しい端末で読み込んでください。

4. Wi-Fi でやりとり（同じ Wi-Fi の中の自分の機器との受け渡し）

「データと設定 → Wi-Fi でやりとり」を利用者が開いて操作したときだけ、同じ Wi-Fi（LAN）の中にある利用者自身の機器（話題コンパスの入った PC・スマホ）と、 すべてのデータ（人物メモ・組織・ネタ帳・予定・話題案・一言メモ・自分で追加した趣味）を直接受け渡します。

  • インターネット上のサーバー・開発者・第三者を経由しません。インターネットへは出ません。
  • 一方の機器で「受け取る」か「渡す」を選んで待ち、もう一方の機器で相手を選び、待っている機器の画面に出る 4 桁の確認コードを入れたときだけ通信します。 「渡す」で待っている間だけ、確認コードを知っている相手がデータを取り込めます。
  • 通信は暗号化します（毎回使い捨ての鍵交換と AES-GCM。確認コードを知らない機器は内容を読めません）。
  • 受け取ったデータは、利用者が読み込み方（追加・更新 / 置き換え）を選ぶまで保存しません。
  • 待っている機器は、同じ Wi-Fi の中で見つけてもらうために、端末の名前と待ち受けのポートを Wi-Fi の中に知らせます（mDNS / DNS-SD）。待ち受けをやめると知らせるのもやめます。
  • 公衆 Wi-Fi など他人と共有するネットワークでは使わず、自宅や職場など自分の管理する Wi-Fi で使ってください。

5. 権限について

Android 版が使う権限はインターネット（INTERNET）だけです。Android では同じ Wi-Fi の中の機器との通信にもこの権限が必要なためで、 上の「Wi-Fi でやりとり」以外には使いません。インターネット上のサービスへは接続しません。 位置情報・連絡先・カメラ・マイク・ストレージなどの権限は使いません。 画面を消えにくくする機能（その場モード・Wi-Fi で待っている間）は権限を必要としない画面の設定で、データの取得はしません。 PC 版は、PC で待ち受けるときに Windows のファイアウォールの許可を求められることがあります（許可しなくても、スマホ側で待って PC からつなげば使えます）。

6. データの削除

Android 版はアプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。 PC 版はアンインストールのときにデータ（%APPDATA%\TalkCompass）を削除するかを選べます（既定は残します）。 人物・予定・ネタなどはアプリ内から個別に削除できます。 残しておきたい場合は、アンインストールの前に「データと設定 → 書き出す」で控えを取ってください。

7. 第三者提供

本アプリの開発者は、利用者のデータを取得しません。したがって第三者へ提供することもありません。

8. 配布元について

本アプリ（Android 版）は GitHub での APK ファイルの直接配布で提供しています。 ダウンロードの際、GitHub（GitHub, Inc.）に IP アドレスなど通常の通信の情報が届きますが、これはブラウザでの Web の閲覧と同じもので、本アプリが送るものではありません。

9. ポリシーの変更

内容を変更する場合は、本ページを更新し、改定日とともにお知らせします。

10. お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせ先: GitHub の Issues
