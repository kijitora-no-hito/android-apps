話題コンパス プライバシーポリシー

「話題コンパス」（以下、本アプリ）は、懇親会や飲み会などに向けて話題の案を準備するためのアプリです。 本アプリは利用者の個人情報を収集・送信しません。

本アプリは権限を 1 つも使わず、インターネットにも接続しません。 入力した内容は端末の中だけに保存され、開発者を含む外部へ送られることはありません。 話題のヒントはアプリに同梱した文章から選んで表示しているだけで、生成 AI や外部のサービスには問い合わせません。

1. 取り扱う情報

情報保存場所外部送信
人物メモ（呼び名・関係・業界・出身・趣味・タイプ、日付つきのメモ）と自分のプロフィール 端末内のアプリ専用領域（データベース） なし
予定（日時・場面・お店・料理・参加者・メモ）、話題案、振り返りの評価、一言メモ 端末内のアプリ専用領域（データベース） なし
ネタ帳、自分で追加した趣味 端末内のアプリ専用領域（データベース） なし

本アプリは、広告・アクセス解析・クラッシュレポートのいずれのサービスも組み込んでいません。 利用状況の記録や送信も行いません。アカウント登録もありません。

2. 人物メモについて

人物メモには、利用者が入力した他の人の情報（呼び名・勤め先の業界・出身・趣味・会話のメモなど）が含まれます。 これらは端末の中だけに保存され、本アプリが外部へ送ることはありません。 書き出したファイルを他の人と共有したり、クラウドストレージに保存したりするときは、その扱いにご注意ください。

3. 書き出しと読み込み（バックアップ）

「データと設定」の［書き出す］を押したときだけ、すべてのデータを 1 つの JSON ファイルにして、 利用者が Android の標準のファイル選択画面で選んだ場所に保存します。 ［読み込む］は利用者が選んだファイルだけを読み込みます。本アプリが自動でどこかへ保存・送信することはありません。 保存先（端末内、SD カード、クラウドストレージのアプリなど）での取り扱いは、その保存先のサービスに従います。

本アプリは Android の自動バックアップ（Google アカウントへのクラウドバックアップ・機種変更時のデータ転送）の対象から外しています。 機種変更のときは、書き出したファイルを新しい端末で読み込んでください。

4. 権限について

本アプリは権限を要求しません（インターネット・位置情報・連絡先・カメラ・マイク・ストレージなど、いずれも使いません）。 画面を消えにくくする機能（その場モード）は権限を必要としない画面の設定で、データの取得はしません。

5. データの削除

アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます。 人物・予定・ネタなどはアプリ内から個別に削除できます。 残しておきたい場合は、アンインストールの前に「データと設定 → 書き出す」で控えを取ってください。

6. 第三者提供

本アプリの開発者は、利用者のデータを取得しません。したがって第三者へ提供することもありません。

7. 配布元について

本アプリは GitHub での APK ファイルの直接配布で提供しています。 ダウンロードの際、GitHub（GitHub, Inc.）に IP アドレスなど通常の通信の情報が届きますが、これはブラウザでの Web の閲覧と同じもので、本アプリが送るものではありません。

8. ポリシーの変更

内容を変更する場合は、本ページを更新し、改定日とともにお知らせします。

9. お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせ先: GitHub の Issues
